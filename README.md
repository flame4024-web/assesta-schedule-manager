# 어세스타 인트라넷 캘린더 매니저 (ASSESTA Calendar Manager)

> **어세스타 인트라넷(`https://it.assesta.com`) 일정 통합 관리 웹 애플리케이션**  
> 브라우저 확장 프로그램의 불안정성(권한 오류, 렌더링 지연, UTF-8 한글 깨짐)을 완벽히 해결하고, 어느 기기에서나 마우스 클릭만으로 일정을 관리할 수 있는 모던 웹 도구입니다.

---

## 🌟 주요 기능

1. **📅 월간 캘린더 인터페이스**
   - 월간 달력 그리드에 인트라넷 등록 일정 뱃지 표시 (긴 제목은 깔끔하게 말줄임 처리)
   - 날짜 빈칸 클릭 시 해당 일자로 간편 등록 폼 즉시 오픈
   - 일정 클릭 시 모달 팝업에서 **전체 제목** 및 **세부내용 본문(메모)** 완벽 복원 표시 및 수정/삭제 연동

2. **➕ 개별 일정 간편 등록 (단건)**
   - 일자, 시작/종료 시간, 구분(프로젝트, 미팅, 업무 등), 제목, 내용 입력 후 원클릭 전송
   - 전사 주소록 드롭다운 선택으로 참조자(`ccAddr`) 자동 포맷팅 (`이름, ` 형식 유지 및 SQL 오류 방지)

3. **📊 구글 시트 / 파일 일괄 등록 (다건)**
   - **[시트 열기 ↗]** 바로가기 버튼을 통해 원본 스프레드시트 즉시 이동 확인
   - 구글 스프레드시트 링크 입력 후 원클릭 불러오기 및 오프라인 CSV 파일 지원
   - **RFC 4180 완벽 호환 파서**: 본문 내 개행(엔터) 및 따옴표가 포함된 일정도 데이터 손상 없이 100% 파싱
   - **사전 검증(Dry-run) 및 유연한 편집**:
     - 불러온 일정 테이블에서 개별 행 실시간 수정(모달 지원)
     - 불필요한 일정 단건 삭제 및 체크박스 선택 일괄 삭제 기능
     - 원하는 항목만 선택 등록 및 순차 전송 프로그레스 바(진행률) 실시간 표시

4. **🔍 일정 검색 & 관리 (CRUD 전체)**
   - 실시간 키워드 검색 (제목, 일자 필터링)
   - 테이블 내 말줄임 없는 **전체 제목 표시** (2줄 반응형 줄바꿈 레이아웃)
   - [수정] 클릭 시 **세부내용 본문까지 완전히 연동**되어 편리하게 수정 (`mode=MOD`)
   - 단건 및 선택 일정 삭제 (`mode=DEL`)

5. **🎨 프리미엄 다크/라이트 테마**
   - 모던 글래스모피즘 & 부드러운 반응형 레이아웃 (모바일/태블릿/데스크톱 완벽 대응)

## 🚀 실행 및 배포 방법

### 1. 로컬 PC / 사내망에서 실행 (더블 클릭)
1. [`웹실행.bat`](웹실행.bat) 파일을 더블 클릭합니다.
2. 자동으로 브라우저가 열리며 `http://localhost:8000` 화면이 표시됩니다.
3. 동일 사내망(와이파이)에 연결된 동료는 `http://[호스트_IP]:8000` 링크로 접속하여 함께 사용할 수 있습니다.

### 2. GitHub & Vercel 온라인 배포 (어디서나 웹 링크로 접속)
1. GitHub 저장소: [`flame4024-web/assesta-schedule-manager`](https://github.com/flame4024-web/assesta-schedule-manager)
2. 온라인 라이브 URL: [https://assesta-schedule-manager.vercel.app](https://assesta-schedule-manager.vercel.app)
3. 스마트폰, 태블릿, 외부 PC 어디서나 브라우저로 즉시 접속 가능합니다.

## ⚙️ 인트라넷 로그인 세션 설정 (최초 1회)
1. 크롬 브라우저에서 `https://it.assesta.com`에 로그인합니다.
2. 키보드 `F12` (개발자 도구) → **Application(애플리케이션)** → **Cookies(쿠키)** → `https://it.assesta.com` 클릭.
3. `ASPSESSIONID...` 이름의 쿠키 값을 복사합니다.
4. 웹 앱 상단의 **[환경 설정]** 탭에 붙여넣고 [설정 저장]을 누르면 즉시 동기화됩니다.

## 🛠️ 기술 스택
- **프론트엔드:** HTML5, Vanilla CSS3 (CSS Variables, Glassmorphism), Vanilla JavaScript SPA
- **백엔드 프록시:** Python 3 (requests, beautifulsoup4) / Vercel Serverless Function
- **인코딩 처리:** EUC-KR 양방향 변환 (인트라넷 레거시 ASP 호환)
- **배포 환경:** Local Web Server (localhost:8000) & Vercel Serverless Platform
